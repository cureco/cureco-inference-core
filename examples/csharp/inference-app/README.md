# Inference app

C# WPFによるSDK利用例です。InferenceApp.slnをVisual Studioで開いてください。
Cureco.Inference.Core NuGetを参照し、SDKソースを直接参照しません。

ONNX・画像読み込み、推論、検出枠/マスク表示、JSON/PNG保存、認証付きローカルAPI、
起動設定保存、API自動開始、GUI最小化、--serveによるGUIなし起動に対応します。
カメラ・PLC接続、補助入力UIは含みません。
